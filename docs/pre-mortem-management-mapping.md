# Pre-mortem: management mapping (#44)

| Failure mode / early signal | Prevention and required response | Evidence to retain |
| --- | --- | --- |
| A reader accepts a target before its authority, or accepts a stale/foreign envelope. Signal: missing control root, fingerprint/ACL/identity mismatch, unknown version, or changed generation. | Verify control-root → wrapper → target in that order. M alone writes; B consumes read-only and invalidates affected sessions for re-registration. Reject; never infer or silently remap. | Version, corruption, identity/ACL, generation, and remap invalidation fixtures; redacted audit-chain event. |
| A token value reaches state, fingerprint, CLI output, or audit. Signal: token-like text in a state/audit/output scan. | Protected stdin only; strict parser; host-set fingerprint covers UTF-8-byte-sorted host IDs only. Redact protected fields and bound diagnostics. Stop rotation and revoke exposed material. | Secret-scan result, exact formula review, and redacted status receipt. |
| A bootstrap actor impersonates the owner or collapses actor/target identity. Signal: principal does not match OS identity, is malformed, or actor equals target. | Bootstrap is owner-only and requires explicit distinct `uid:`/`sid:` actor and target principals. Credential management remains owner-only. | Native principal/refusal evidence and audit entry with non-secret principal identifiers. |
| Publication becomes visible before its prerequisites, or admission reopens without finality. Signal: TF/A absent before publication, TF commit absent before Zf/RP/AK/FP/receipt, or reopen failure. | Enforce GR → TF reservation → A → reader floor → publication → TF commit → Zf → RP → AK → FP → receipt → reopen. TF/A precede publication; TF commit is post-publication and preproof. | Ordered native write trace and terminal receipt/finality-proof fingerprints. |
| Crash, competing writer, or audit failure creates a plausible but unproven route. Signal: CAS/lock/fence/lease/audit/reopen error or interrupted recovery record. | Native ordered locks and CAS; audit-chain every transition. Fail to `manual_cleanup` and `no-route`; native idempotent recovery only. | Crash/CAS/dual-writer/recovery fixtures and recovery disposition. |
| An untouched legacy file is accidentally normalized, altered, or routed. Signal: target bytes, identity, length, or ACL differs from retained record. | Treat `legacy-retained` as an exact retention exemption with `no-route`; management must not publish a replacement target. | Raw-byte, identity, ACL, and no-route checks. |
| A JavaScript fallback writes control state when the addon is missing or tampered. Signal: manifest/package/N-API/platform/architecture/capability/SHA mismatch or no addon. | Refuse before writes. Require verified native addon and native no-follow/ACL/atomic-write capability. | Build-manifest verification and refusal tests. |
| Operators mistake #44 completion for serving approval. Signal: daemon/readiness instructions or service rollout derived from mapping documentation. | Keep serving/readiness blocked and out of scope. Do not add OAuth, daemon, network, deployment, or `ops/` procedures here. | Review of scope and separate native-serving gate evidence. |
| **PM-MP-FENCE-1:** a populated successor combines top-level F+1 with retained mapping/route fences F and fails snapshot validation before CAS. | Validate the untouched predecessor and exact CAS first; construct a separate complete F+1 graph with recomputed fingerprints. Reuse the transform in mapping/token preparation and recovery, and persist the complete terminal graph. Never loosen shared/native equality or skip fence advancement. | MP-FENCE-REPRO-001 baseline failure with zero successor writes; multi-mapping/multi-route create/update/revoke/rollback and token regressions; exact stale CAS; candidate-bound finality/recovery proof. |
| **PM-MP-ARCHIVE-1:** a tombstone uses a live re-fenced fingerprint, or historical routes are treated as current membership after channel reassignment. | Validate immutable mapping/routes internally and require mapping-only re-fence equivalence to the predecessor. Use original archive mapping fence/fingerprint for tombstones and candidate F+1 for handoffs. Derive current removals from the predecessor; never rewrite retained history or forbid existing reassignment. | MP-FENCE-ARCHIVE-001: immutable-byte comparisons, missing/invalid/drifted archive refusals, token/unrelated successor before revoke/rollback, and reassigned-channel coverage. |
| **PM-MP-SCOPE-1:** graph-wide cryptographic carry-forward silently broadens mapping authority or bypasses close/drain/finality. | Preserve mapping-scoped operation IDs, token all-scope policy, the global closed-drained/zero-outstanding/no-route contract, and exact B completion proof. Stop if correction requires a native/schema/authority change. | MP-FENCE-SCOPE-001 and MP-FENCE-FINALITY-001; distinguish JavaScript adapter traces from fresh OS-native lock/ACL/durability evidence. |
